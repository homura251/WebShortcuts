# 隐私说明

WebShortcuts 将收藏标题、标签目录及关联、网址、网站图标、自定义图标和编辑草稿保存在应用的设备私有目录。没有用户账号、后台云同步、广告或统计 SDK，也不会把收藏、导入图片上传到开发者服务器。

自动获取图标时，应用会直接访问填写的网站及网页声明的图标/Manifest 地址。这些请求会向相应网站暴露正常网络请求必需的信息（例如 IP 地址和请求路径），但不包含 Chrome Cookie。图标资源可能位于网站使用的第三方 CDN。使用生成图标或自定义图标不需要为图标进行网络下载。

选图使用 Android 系统 Photo Picker；不申请对整个相册或存储空间的读取权限。选中的图片经过本地尺寸和格式检查后，复制为应用私有图片，不改变原照片。为支持再次裁切，会保留经过方向校正、最长边不超过 2048 像素的私有原图副本及裁切坐标；不保留对原照片的长期 URI 访问权限。未保存的原图/预览位于私有草稿缓存，保存后使用版本化私有文件。

网页浏览交给 Chrome Custom Tabs 或系统可用浏览器处理。网页的 Cookie、登录状态、历史记录及权限由该浏览器和目标网站管理，WebShortcuts 不读取它们。

应用关闭 Android 自动云备份和设备迁移数据提取。用户可主动通过系统文件选择器导出 ZIP 完整备份或 HTML 书签，也可选择文件导入；不申请广泛存储权限，不保留外部文件的长期访问权限。导入文件先复制到受限私有缓存，操作结束后清理，中断遗留缓存在下一次打开导入导出时清理。

ZIP 备份未加密，包含收藏网址、标签目录及关联、图标、私有原图、裁切参数、来源时间及外观设置；HTML 仅包含名称、网址与可用时间信息。导出范围为全部收藏。文件保存到用户选择的位置；如选择云盘文件提供者，文件存储由该提供者负责，应用不会另外上传到开发者服务器或自动同步。导入 HTML 不会自动联网抓图，也不会迁移浏览器 Cookie 或登录态。

删除收藏会清理不再被引用的图标；卸载应用会删除收藏及全部私有图片。已导出到所选位置的文件不会随卸载删除。请先完成所需备份再卸载测试包。

用户主动输入的 HTTP 网站可能以明文传输图标请求，应用保留该能力以支持局域网系统；未填写协议时默认使用 HTTPS。
